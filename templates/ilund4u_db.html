Description

Welcome to the iLund4u phage database!

iLund4u is a bioinformatics tool designed for the search and annotation of accessory genes and hotspots across large datasets. We recommend visiting the tool's Home page, where you can find a detailed description of the algorithm and full documentation.

This iLund4u phage database provides an interactive platform to explore hotspot-encoded phage proteins annotated with iLund4u, using the complete PhageScope database of 873K phage genomes as input.

You can also access the web version of iLund4u on our server portal which can be used to find whether homologues of your query protein are encoded in hotspots.

The results generated in the web version are directly linked to the data and pages of this database.

Database overview

iLund4u includes two precomputed hotspot databases derived from phage and plasmid sequences. This online resource catalogues phage-associated hotspots and accessory protein clusters. It consists of 242.8K protein clusters encoded in 16K hotspots across 218K phage genomes, remaining after deduplication and filtering of the initial PhageScope dataset.

Protein Clusters

Here you can find all protein clusters encoded at least once as cargo in phage hotspots — a total of 242,773 representative sequences. Each protein cluster has its own database page with a detailed description. Note that you can also find protein clusters homologous to your query protein using the iLund4u web search tool.

Phages

This dataset includes 217,963 phage genomes that remained after deduplication and filtering of the initial PhageScope collection using the iLund4u algorithm. Each phage has its own database page containing description and classification of its proteins as variable, conserved, or intermediate. In addition, each phage is assigned to a proteome community — a group of related phages sharing a core proteins.
