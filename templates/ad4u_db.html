Description

Welcome to the AD4u protein database!

This AD4u database provides an interactive platform to explore hotspot-encoded phage proteins annotated with iLund4u, using 63K Enterobacteriaceae-infecting phage genomes from the PhageScope database and the Durham, BASEL, and LUND phage collections. Using genomic location information, we reduced the set of putative anti-defence and defence-trigger proteins to ~1.6K protein clusters and co-folded them by AlphaFold3 with a library of immune system proteins to identify putative binders of defence system protein.

Analysis pipeline

Experimentally validated inhibitors

Based on AlphaFold3 predictions of hotspot-encoded phage proteins, we experimentally tested 20 binder–defence gene pairs. Of these, 10 pairs, comprising four unique binders, were experimentally validated. These novel verified systems include anti-toxSAS, anti-RT, anti-Avs2, and anti-DRAKEN counter-defence proteins.

Hotspot encoded putative binders of defence components

This dataset includes 1,638 phage protein clusters that were annotated across Enterobacteriaceae-infecting phage hotspot. After co-folding against the library of 720 defence system proteins from Defense Finder database (>1.1M combinations), we identified 598 putative binders of defence system proteins.
